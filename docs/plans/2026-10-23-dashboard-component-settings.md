# Dashboard 组件设置开发方案

日期：2026-10-23。A 批已完成实现、两端契约与测试、NAS 测试部署和人工真机验收。
后续 UI 精简已完成本地验证与签名编译；新版 UI 仍待手机重新连接后安装。B 批未开始。

## 目标

在 App 内编辑现有 Dashboard 的内容参数，不要求页面先声明自定义输入。
保留基本设置、冲突处理、预览及手动推送；完整布局和代码仍使用网页。

## A 批交付

### 服务端

- 发现 Grid cell、Canvas widget/data element、Code widget source 和 binding 选项。
- 既有 Canvas inputs 优先，去重匹配字段；显式多目标声明可控制多个片段，多个不同值
  需要用户明确设置统一值。组件实例独立，不按 Widget 类型隐式联动。
- 字段定义、默认值、类型、约束、秘密标记及稳定标识由服务端提供。无法支持的定义
  局部只读，不阻断其他字段。读取默认值不写入配置。
- 新增可选 `dashboard_settings` / `dashboard_component_settings` 能力；编辑需要单独
  授予 `dashboards:write`，读取沿用 `dashboards:read`。

| 接口 | 用途 |
| --- | --- |
| `GET /api/app/v1/dashboards/{id}/settings` | 基本设置、声明输入、组件分组、覆盖状态及修订号 |
| `PATCH /api/app/v1/dashboards/{id}/settings` | 原子保存基本设置、输入和组件变更，或移除默认覆盖 |
| `GET /api/app/v1/dashboards/{id}/settings/fields/{field_id}/choices` | 当前字段的搜索、分页及刷新 |

- 页面修订与字段定义修订共同防止旧草稿写入新目标。校验失败不产生部分保存；
  重复目标更新被拒绝。省略、清空、恢复默认有独立语义。
- 秘密当前值、默认值、别名及候选项脱敏，保留未编辑的未知或隐藏配置。
- 复用 Widget 动态选项来源；区分空结果与加载失败；保留已失效的已选值，并验证新值。
  多选保留数组顺序，支持媒体播放器优先级。
- Album/Emby 共享参数声明已在无绑定副本中验证；未改写正式页面的声明或值。

### App

- Dashboard 卡片名称或列表行进入设置。顶层统一草稿和 Save，组件子页返回保留修改。
- 共享控件支持文字、数字、布尔、单选和有序多选；帮助、默认值和重置/清除按需展开。
  显示屏、更新和外观进入独立子页，网页字段默认折叠。
- 选择页保留不可用的已选值，去掉重复候选行，提供搜索、分页、重试和固定的完成按钮。
- 保留秘密替换/保留/清空、未保存退出保护、权限提示和冲突后保留草稿。
  保存刷新列表与预览，不自动推送屏幕；断连或切换服务器不复用旧请求结果。
- 旧服务端解码空组件，不发送扩展字段；完整布局、代码、地点和条件控件保留网页入口。
