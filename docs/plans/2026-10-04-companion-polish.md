# Companion 配置体验优化计划

## 范围与顺序

本轮接续品牌识别、第一批服务端能力跟进和 Lineup 表单精简，在 canonical
`main` 工作树实现。保留已有改动，不创建新版本或发布标签。

1. **选择与时长**：统一 Dashboard 选择器的序号、勾选及操作层级；保留搜索、
   拖动排序和滑动移除，提供 VoiceOver 排序动作；时长弹窗按内容测量高度，
   大字号时允许滚动，保留服务端支持的长间隔。
2. **编辑保护**：以语义草稿判断真实修改，覆盖 Cancel、返回类型选择以及整张
   sheet 的下滑关闭（包括打开子选择器时）。无修改直接退出；Keep Editing 保留
   草稿；保存期间禁止退出。单设备自动选择和加载已有记录不视为用户编辑。
3. **Cycle 时间**：折叠的时间设置提供“每天开始于”；保持服务器墙钟 HH:mm，
   不按手机时区换算，不受手机当日 DST 跳变影响。仅提交修改字段，已有单页
   Lineup 仍可编辑，非默认时间与时长不被默认值覆盖。
4. **设备详情**：当前画面、Next in Line、连接与电量直接可见；品牌型号保留
   简洁摘要，Hardware/Panel 的低频字段合并到默认收起的 Device Details。
5. **验证与交付**：模型/请求测试、四种编辑流程和退出保护 UI 回归；浅色、深色、
   大字号截图核对；更新连接的 iPhone 并区分编译、安装、启动结果；将本轮及
   前几轮已授权改动整理为功能提交，不自动推送或发布。

## 接口核查后的调整

以 `tesserae-upstream upstream/main 22f2aeb9` 为服务端基线：

- Keep Fresh 的 `anchor` 当前被调度器忽略；实际从上次刷新累计间隔。此次不
  展示无效的“刷新起点”控件，读取/编辑仍保留已有字段。
- Cycle 的 `anchor` 不只是显示用重置点：每天在该时间从第一页开始，在当天
  起点之前循环暂停。UI 明确解释这一影响。
- 时间使用服务器时区；服务器 `system` 回退与 Companion 元数据存在差异，
  UI 不无条件把返回的 UTC 当作实际服务器时区。
- 服务端允许已有单页 Cycle/Manual；编辑时可保留单页，新建仍引导至少两页。
- 最长间隔/停留时长为 10080 分钟；时间控件不得把 >24h 的已有值显示为24h。

## 验收重点

- 退出未修改表单不弹提示；修改后返回/取消/下滑均不丢草稿；子选择器普通返回
  不应被误认为退出整个编辑流程。
- 修改名称空白、设备顺序、派生绑定标志，或改后还原，不应造成误报。
- 调整 Cycle 起点再重新打开，值保持一致；Daily/Manual 无起点字段；Keep Fresh
  无不起作用的时间入口。
- 排序、移除、单选返回、多选 Done 以及时间改变后的保存均可用；大字号下
  操作可达，弹窗没有不必要的空白。
- Device Details 默认收起，展开可访问所有原字段、复制 ID，缺失值仍显示
  Not reported；模拟器验证不代替真实墨水屏联调。
